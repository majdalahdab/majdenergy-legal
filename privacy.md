# Privacy Policy

**MajdEnergy Content Pipeline**

_Last updated: August 16, 2026_

## 1. Overview

MajdEnergy Content Pipeline ("the Tool") is a personal-use software application built and operated by an individual based in the United Arab Emirates ("the Operator"). The Tool retrieves the Operator's own social media metrics from TikTok, YouTube, and Instagram for personal analytics purposes.

The Tool is single-user. It is not offered as a public service, is not made available to other users, and does not process personal data belonging to anyone other than the Operator.

## 2. Who Operates This Tool

- Operator: An individual based in the United Arab Emirates
- Contact: [CONTACT_EMAIL]

## 3. Data We Access

The Tool connects to the following platforms using their official APIs, solely to retrieve data belonging to the Operator's own accounts:

- TikTok (Display API): using the scopes user.info.basic, user.info.profile, user.info.stats, and video.list, to retrieve the Operator's own TikTok profile information and video metrics (views, likes, comments, shares).
- YouTube: the Operator's own channel and video statistics.
- Instagram: the Operator's own account and content metrics.

No data is ever collected, viewed, or processed about any other individual, account, or user. The Tool does not have, and does not request, the ability to act on behalf of, or access data belonging to, any account other than the Operator's own.

## 4. How Data Is Stored

All retrieved data is stored locally, in a SQLite database file on the Operator's personal Windows laptop. Data is not:

- transmitted to any remote server, cloud service, or hosting provider,
- sold, rented, or shared with any third party,
- used for advertising or ad targeting, or
- used to track the Operator or anyone else across other sites or services.

There is no backend server, hosted database, or cloud storage component to this Tool. The local SQLite file is the only place data is kept, and it remains under the Operator's exclusive control.

## 5. Data Retention & Deletion

Data remains in the local SQLite database until the Operator manually deletes it. Since the database lives only on the Operator's own machine, it can be deleted at any time by deleting the local file. There is no remote copy to separately request deletion of.

## 6. Third-Party Platform Terms

Use of the TikTok, YouTube, and Instagram APIs by this Tool is subject to each platform's own developer terms and API policies. This Privacy Policy covers only the Tool's own handling of data; it does not modify or supersede the privacy policies of TikTok, YouTube, Instagram, or any other third-party platform.

## 7. Revoking Access

The Operator may revoke the Tool's access to any connected platform at any time via that platform's own account/app-authorization settings (e.g., TikTok's connected-apps settings, Google Account permissions, or Instagram's authorized apps).

## 8. Children's Privacy

This Tool is a personal, single-user utility operated by an adult for their own analytics and is not directed at, marketed to, or used by children.

## 9. Changes to This Policy

This Privacy Policy may be updated from time to time to reflect changes to the Tool. The "Last updated" date above will be revised accordingly.
